# Nova Studio — Responsive Web Design (Week 2)

## Project overview
A responsive creative-studio landing page built with semantic HTML5 and CSS3. The page includes a navigation bar, hero section, service cards, about section, contact call-to-action and footer.

## Files
- `index.html` — page structure and content.
- `style.css` — visual design, layout, responsive breakpoints and mobile navigation.
- `REPORT.docx` — project documentation suitable for the internship submission.

## How to run
1. Extract the project ZIP.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in any modern browser. No build tools are required.

## Responsive approach
- Desktop: two-column hero and three-column service grid.
- Tablet (850px and below): tighter spacing and simplified about layout.
- Mobile (600px and below): single-column sections and collapsible CSS-only navigation.
- Small phones (360px and below): compact spacing and stacked hero actions.

## Testing
Resize the browser or use developer tools to test common widths such as 1440px, 1024px, 768px, 390px and 320px. Check navigation, text wrapping, cards, buttons and horizontal overflow.

## Customization
Replace the sample studio name, text, email address and colors with your own details before final submission.
